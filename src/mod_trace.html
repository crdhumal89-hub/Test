Two population modes.
⚑ Corrections only — pre-fills only the rows that need fixing (MISSING and OVERTAGGED). Use this when you want to act on the engine's specific findings. AMBIGUOUS rows are not auto-included; add them manually via the + Add to fix list buttons on the Investigation tab if you decide they need fixing.
⤓ Full population — pre-fills every Investor→Investee allocation in the lookthrough for this product (every wrapper-shape holding regardless of flag status). The notes columns mark which rows are existing-correct (KEEP), proposed corrections (SET_LINKED_Y / FLIP_LINKED_TO_N), or ambiguous (REVIEW). Use this when you want to bulk-load a complete LTAT snapshot or audit every allocation in one place.

Schema. Default schema is the LTAT Bulk Upload (16 cols): Sent By · User ID · Investor Name · Investor Code · Investor Type · Investee Name · Investee Code · Investee Type · Linked Security · Clearing Broker · Allocation · Begin Date · End Date · Verification · Upload · Status. The first two columns (Sent By, User ID) are pre-filled with the product controller as an EXAMPLE — replace with your own name & User ID before upload. Allocation is also left blank — controller supplies per-investee % summing to 100%. Investor / Investee Name auto-populate as the plain entity name, with Investor Code / Investee Code in their own columns. Linked Security auto-populates as the real Sec Master symbol (source Security Code, e.g. AAASF1Y - SPV NEWCO). Begin / End Date default to first / last day of the data's as-of month. Verification / Upload / Status are blank for the LTAT operator. Switch to "LTAT Allocation Tracker UI" for the legacy 10-col format, or "LTAT + Notes" for internal annotations (Action / Current Y / Proposed Y / Severity / Reason — strip before LTAT load).

What you need to fill in. Allocation % is always left blank — LTAT requires percentages to sum to 100% per investee, so the controller must enter the correct split (refer to MicroStrategy / your fund records). Investor Type defaults to SPV; change to Fund / Product / CLO if applicable. Start Date defaults to today; End Date defaults to 9999-12-31 (LTAT perpetual end convention from the screenshot).
